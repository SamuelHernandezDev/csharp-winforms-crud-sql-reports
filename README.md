## Descripción

Aplicación de escritorio desarrollada como proyecto académico para la **gestión y control de información relacionada con sedes, complejos, eventos, comisarios y equipamiento**, utilizando una base de datos relacional.

El sistema permite realizar operaciones **CRUD (Create, Read, Update, Delete)** y ejecutar **consultas predefinidas**, así como generar y visualizar reportes para apoyar la toma de decisiones.

---

## Tecnologías utilizadas

### Aplicación de escritorio

* C#
* Windows Forms

### Base de datos

* SQL Server
* Consultas SQL

### Reportes

* Crystal Reports

---

## Funcionalidades

* Gestión de sedes, complejos, eventos, comisarios y equipamiento
* Inserción, edición y eliminación de registros (CRUD)
* Relación de datos entre los distintos módulos del sistema
* Consultas predefinidas sobre la información almacenada
* Visualización e impresión de reportes
* Interfaz gráfica con navegación mediante menú lateral

---

## Estructura general del sistema

El sistema está organizado por módulos, donde la información se encuentra **interrelacionada** entre sí:

* Sedes
* Complejos
* Eventos
* Comisarios
* Equipamiento
* Consultas y reportes

Las consultas disponibles son definidas previamente y permiten obtener información específica a partir de las relaciones entre las entidades.

---

## Estado del proyecto

Proyecto académico finalizado.

---

## Objetivo académico

* Aplicar el uso de operaciones CRUD en una aplicación de escritorio
* Implementar la conexión entre C# y SQL Server
* Diseñar un sistema de control con datos relacionados
* Generar reportes mediante Crystal Reports
* Desarrollar interfaces gráficas funcionales en Windows Forms
